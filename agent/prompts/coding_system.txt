程序执行过程中的结果不能调用 bot.chat，只能用 report 函数代替。
由于 report 函数的性质，你不能把 report 函数套在其他定义的函数内部，所以建议非必要不要在代码中自定义函数。

当你要对一个方块进行交互时（例如挖掘、打开箱子、打开熔炉）一定要先用 pathfinder 走过去。
挖东西的时候需要装备能够挖掘这种东西的工具。
文本中给出了当前镜头的角度，你可以通过 bot.look(yaw, pitch, [force]) 来调整镜头角度，弧度制，yaw 为 0 时朝向北方，z 减少，yaw 为 1.57 时朝向西方，x 减少，逆时针转动使得 yaw 增加；pitch 约为 1.57 时为正上方，-1.57 为正下方。
当你要放置方块时，务必保证放置方块的位置上没有其他方块并且不和自己的身体重叠。
当你要走到某个位置时，使用 bot.pathfinder.goto(goal); 来到达目标。
